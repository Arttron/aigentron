Aigentron v0.1.129

For people who are not programmers: every message in a chat has a link you can copy and hand to an agent, a lead agent can read a subtask's long answer in full, and the technical lines no longer clutter the chat.

New
- Every message in a chat has a "copy link" button (next to copy and quote). Opening the link scrolls the chat to that message and highlights it until you click in the chat or reload the page. Paste the link to an agent and it reads the message from the server itself (new tool read_message; only messages of the same project).
- When a subtask's answer is longer than 4000 characters, its lead agent now gets a link to the whole answer in the report and reads the rest itself, instead of being left with a cut text.

Changed
- The chat view "messages only" no longer shows the technical lines (a tool server that is not connected, the list of tools in a run); they are in "all steps".
- A message opened from a search result stays highlighted until you click in the chat (before: a short flash).
