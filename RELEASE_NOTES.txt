Aigentron v0.1.76

For people who are not programmers: choosing Codex now installs it for you and takes you straight to signing in.

New
- Codex is installed on demand. Create a Codex provider (or press "Sign in" on one) and, if the Codex program is not on the server yet, the server installs it first (about 330 MB, needs 500 MB free and npm), then starts the sign-in: open the link, enter the code. Nothing to do in a terminal. Claude's program ships with the server, so for a Claude subscription you go straight to signing in.
- A newly created Codex / Claude-subscription provider opens directly into this flow.
- The location can be moved with CLI_DIR; a Codex you installed yourself (CODEX_BIN) or one baked into the Docker image is used as before.

Update note: no database changes.
