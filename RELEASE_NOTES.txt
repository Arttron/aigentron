Aigentron v0.1.55

For people who are not programmers: the chat shows that something is happening, agents stop piling up tasks, subtasks fold away, and the documentation is brought up to date.

Chat
- A thin strip is now the bottom edge of the chat window. While a request is in flight a light runs along it; every thinking step or action from the agent makes it flash in a random spot, and new messages rise out of it. Classic look: multicoloured flashes and a light that changes colour as it goes. Terminal look: 8-bit pixels and palette.
- "agent is working" is shown plainly; the note about a slow first reply appears only for local (Ollama) models. If nothing arrives from the agent for 30 seconds you see a "no reply" notice (the task is not stopped).

Subtasks
- Agents no longer multiply tasks: before creating one they check whether the work fits an existing subtask (limit 25 per task). A lead can close its own subtasks itself ("done"). Subtasks fold in the task list and on the task page and show a count and a status summary.

Phones
- The Discuss window opens on phones; the assistant is larger and keeps its animation while thinking.

Docs
- Plans and RFCs now start with a status (done / partial / open); README, roadmap, backlog, feature docs and the admin's own knowledge match the code. New: docs/request-flow (how requests to agents and providers are built, what goes into context, how subtask results come back, how agents gain experience).

Update note: no database changes.
