Aigentron v0.1.31

For people who are not programmers: reminders, a shared library for your project, ready-made starter packs, and Telegram set up by the assistant.

Update note: this release adds one database table (schedules). It is created automatically when the server starts.

Reminders and recurring tasks (Settings → Schedules)
- Post a message to a chat on a schedule (free — no model involved) or start a task for an agent each time (its updates arrive in the chat).
- Set the time in plain words — every day, weekdays, certain days of the week, every N hours — with your time zone and optional quiet hours.
  "Run now" tries a schedule; a run missed while the server was off is skipped, not fired hours late.
- The admin can create and change them for you.

Project library (📚 Resources)
- A shared library of notes, images, PDFs and any files that every agent of the project can use as knowledge: house measurements, a learner's
  profile, a style guide, reference photos. Agents see the titles and descriptions, read what is relevant and never modify the files.
- Upload by button or drag & drop, write notes, add tags, limit an item to chosen agents. The admin can add and edit text notes.

Starter packs (Agents → Starter packs)
- English learning: a tutor, a curriculum planner and a quiz maker, with a learner profile and a list of trusted resources.
- Home renovation: a planner, an estimator, an interior designer and a materials advisor, with a brief, measurements and a budget to fill in.
- Software team: the standard fleet (PM, architect, backend, frontend, designer, reviewer).
- Installing never overwrites what you already have; prepared schedules start switched off. Or just tell the admin what you want to do.

Telegram, set up by the admin
- The assistant creates the channel, asks for the bot token in a secure field (never in the chat) and checks the connection.
- A chat that writes to the bot but is not allowed yet shows up in Settings → Channels with Allow / Dismiss, and the bot tells the person their chat id.
- Keys requested through Telegram arrive as a one-time link (10 minutes, one use) when PUBLIC_URL is set.

Also
- Names of schedules, channels and library items may use letters of any language.
- Fixes found while testing: a dependency cycle that stopped the server from starting, and an upload route that could eat JSON files.
