Aigentron v0.1.64

For people who are not programmers: files with Russian (or other non-Latin) names are now handled safely, and you still see their real names.

Attachment names
- A file you attach to a task is now stored under a plain Latin name: Cyrillic and Greek are transliterated ("кухня 2.jpg" → "kukhnya-2.jpg", "Проект кухни №2.md" → "Proekt-kukhni-No2.md"), accents are removed, scripts that cannot be transliterated become "file.<ext>"; a name that is already taken gets -1, -2. This keeps agents, shell commands, git, links and different operating systems away from non-Latin file paths.
- You keep seeing the real name: the Files tab shows it, a download is saved under it, Telegram gets the file under it. The agent sees both (the stored path and "uploaded as «…»").
- Files attached before this update keep their old names. Library resources already worked this way (stored by id); files in the shared workspace keep the names they are given.

Tests
- The ffmpeg-based tests no longer fail now and then when the whole suite runs in parallel (longer timeout).

Update note: no database changes.
