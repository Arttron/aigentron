Aigentron v0.1.52

For people who are not programmers: a knowledge base your agents can search, plus a few fixes.

Knowledge bases (new page: 🧠 Knowledge)
- Keep large reference material — regulations, manuals, textbooks, saved web pages, your own notes — in a knowledge base. Agents search it instead of carrying everything in the prompt, and cite the source.
- Upload PDF (with a text layer), Word (.docx), Markdown, text, HTML or CSV; write a note; pick something from Resources; or pull in web pages the research tools saved. The same text is never added twice.
- Documents are cut into passages by sections, paragraphs or fixed size; the settings have a preview where you paste a sample and see how it will be cut.
- Search by keywords always works — offline, no key needed (English and Russian). Optionally give a base an embedding model (OpenAI-compatible or local Ollama) and it also finds passages by meaning; the two are combined. It costs a few cents per million words and the text goes to that provider.
- Choose which agents use each base (none = all). Agents get kb_list, kb_search and kb_read, and kb_add only on bases where you allow agents to add notes.

Smaller changes
- Model and voice pickers (Settings → Voice, Vision, and the knowledge base settings) are real drop-downs: suggestions, the models the provider reports, and "Other…" to type a name. They no longer look like browser autocomplete.
- Settings → Version & updates: the Update button no longer sticks to Check now.

Update note: this release adds three small tables for the knowledge base; they are created automatically when the server starts. Scanned PDFs (no text layer) are not readable yet.
