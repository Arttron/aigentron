Aigentron v0.1.47

For people who are not programmers: scheduled tasks now stay in one conversation, and you can make the server refuse access by IP address.

Scheduled tasks (Settings → Schedules)
- A schedule that starts an agent now continues ONE ongoing task by default: every run is a follow-up in the same task, so the agent remembers the earlier runs (for example a daily English lesson that builds on yesterday's). Before, every run created a new task.
- You can still choose "start a separate new task every time" for a schedule. If the previous run is still working, the next one waits in the task's queue; after 30 days a fresh task starts so the conversation does not grow forever.
- The admin assistant can set this too.

Only your domains (Settings → General → Access, or `aigentron access`)
- New option "Only these domains": from outside, opening the server by its IP address or a bare server name gives an error page instead of the dashboard. The server itself (agent hooks, health checks, SSH tunnel) and your domain keep working. The dashboard will not let you switch it on while you are connected by IP, so you cannot lock yourself out.
- This does not replace passwords — set them in Settings → Security as well.

Update note: this release adds two small columns for schedules; they are created automatically when the server starts.
