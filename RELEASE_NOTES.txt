Aigentron v0.1.60

For people who are not programmers: a reliability release — safer updates with backups, fewer ways for a task to get stuck, more honest cost numbers, and smoother handling of files.

Updates and backups
- "aigentron backup" / "aigentron restore": one archive with the database, secrets, your agents, skills, library, attachments and workspace (a timer for daily backups is available, off by default). Before every update the database is snapshotted; if the new version does not come up healthy the update rolls itself back, snapshot included.
- A fresh install now sets a random operator password and shows it once (also saved in secrets/initial-password.txt). Existing installs are untouched.
- Release archives are checked against SHA256SUMS when the release provides them.
- Approvals and questions left over from a previous run are closed when the server starts, so nothing waits forever.

Tasks that get stuck less
- Two follow-ups sent at the same time run one after the other, never twice at once; cancelling or deleting a running task waits for the run to stop; a cancelled task never comes back.
- A task waiting for your answer (ask_user or an approval) no longer runs out of time while you think.
- If the provider fails on a follow-up, the task ends "stalled" with the provider's own error message instead of silently switching models.
- The administrator instructions from Settings now really are added for every agent, as the screen says.

Cost
- Token and cost statistics no longer add the same session's totals again on every follow-up (they were overstated). Daily/per-task token budgets now count cache tokens too, so existing limits are effectively stricter (roughly 5–10 times); raise BUDGET_TOKENS_PER_TASK / BUDGET_TOKENS_PER_DAY if tasks get blocked. Sessions started before this update are counted once from the update on.

Files
- Clips recorded by the browser camera (Chrome/Android) can be looked at by the agents; videos over 95 MB are refused with a clear message (the limit behind Cloudflare); an attachment can only be added to an existing task (1 GB per task); the assistant can read only the attachments of its own task; old versions in the workspace's deliverables are rotated.

Dashboard
- Live lines are no longer lost while a conversation loads and are re-synced after a lost connection; long conversations re-render less; background refreshes pause in hidden tabs.

Update note: the database gets a migration (foreign keys, indexes; orphaned rows are cleaned) — a snapshot is taken first.
