Aigentron v0.1.29

Use the dashboard from your phone, and reach it from anywhere over HTTPS.

Phone layout
- The task page works like an app on a phone: a compact header (with a ⋯ menu), Chat | Files | Tasks tabs, the
  conversation filling the screen and the message box pinned to the bottom (Enter adds a line, ➤ sends).
- In landscape the message box is one slim line that opens a full-screen composer.
- Every page was checked at phone width: task list, settings tabs, usage stats, agents and the add/edit windows.
  Tab strips scroll sideways, rows wrap, tables scroll inside their card; no more page sliding off to the side.
- A "↑" button jumps back to the top of long lists.
- No floating theme switch on phones (Settings → General still has the choice).

The assistant
- Drag the assistant anywhere on the screen; it remembers where you put it.
- Tuck it away to a slim tab on the nearest edge (at the same height); tap the tab to bring it back.
- Settings → General → Assistant → "Reset position / show" puts it back in its corner if it ever gets lost.
- The open assistant chat is readable in the dark theme again (it was a white panel with light text).

Remote access
- Optional Cloudflare Tunnel profile for docker compose (make tunnel-up), PUBLIC_URL, and a step-by-step guide:
  docs/remote-access.md. No ports are opened on the server; put Cloudflare Access in front.
  The API still has no login of its own — see the guide.
