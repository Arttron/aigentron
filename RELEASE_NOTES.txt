Aigentron v0.1.82

For people who are not programmers: you can switch approvals off (for everything, one project or one task), small servers stay responsive under load, long-running agents are no longer cut off while they are still working, and the chat shows colours.

New
- Approvals at three levels. Settings -> General -> Approvals has a "No approvals mode" (administrator): risky agent actions run without a card. A project (its settings) and a task (the shield selector on its page; its subtasks follow it) can override it, in either direction - the most specific level that is set wins. Always still asked: passwords and tokens, the charter and CI files, and everything the admin changes on the platform. /tmp is now a free scratch folder (writes and rm), and rm accepts plain quotes and globs below a named folder.
- Run limits in Settings -> General: the first time window, how far a run that is still working is extended (a run that keeps producing output is no longer cut off after 10 minutes, up to 60), when a silent run is stopped, and steps per run. At the ceiling a card asks whether a run that is still working may go on (+30 minutes per approval; no answer or a refusal stops it, the work done stays).
- Small servers: held runs start one at a time and a few seconds apart; a burstable instance out of CPU credits (CPU steal) holds starts; agent processes run at a lower CPU priority; the Node processes agents start get a memory cap (a third of the RAM on a small machine); "Choose automatically" for parallel runs; a queued task that is held back says why on its page. See docs/small-servers.md.
- Workspace: a project picker - browse a project's own folder and its brief.
- Chat: colour values (#ff8800, rgb(...), hsl(...)) are shown on a chip of that colour with black or white text, whichever contrasts better. An agent can refer to a file of the task by name (![caption](file.png)) instead of repeating it - added in 0.1.81.
- The frontend engineer template asks for components, an MVC split (view + hook) and one CSS Module per component - it was in 0.1.80.

Fixed
- Task titles and the "unrecognized_model ... generate_session_title" error, subtask answers cut at 500 characters - fixed in 0.1.80.

Update note: database migrations add an approval-mode column to tasks and projects (applied automatically).
