Aigentron v0.1.103

For people who are not programmers: documents that agents write can now be opened and read right in the service, and an agent's answer is no longer just "the document is ready".

Added
- A viewer for documents of a task: Markdown is rendered, html is shown safely (no scripts), csv as a table, json formatted, text and pdf as they are. It opens over the page from the chat, from the task's Attachments and from file links in messages; buttons Source, Copy and Download.
- A document an agent saves for you (workspace_save) is posted into the conversation as a chip that opens the viewer, the way pictures were.

Fixed
- Agents sometimes ended with "the document is ready" and the list lived only in a file. The agents' charter now says a document you asked for is answered in the final message itself (long ones: every item in brief plus the file name); "refer to the file, do not repeat it" stays only for pictures, videos and files already shown.

Update note: no database changes.
