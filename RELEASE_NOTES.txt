Aigentron v0.1.88

For people who are not programmers: sign-in can now ask for a code from an authenticator app, and the chat has a full-screen icon.

New
- Two-factor sign-in (optional). Each person turns it on once in Settings → General → Security → Two-factor sign-in: scan a QR code with Google / Microsoft Authenticator, 1Password, Aegis or similar, type the code, and save the ten recovery codes (shown once). After that, signing in asks for the password and then a 6-digit code.
- An operator or admin can require it for a user (a checkbox when adding or editing the user). That person sets it up at their next sign-in and cannot turn it off themselves. "Reset 2FA" in Users helps when a phone is lost.
- The command-line console asks for the code too; for scripts set LDS_ADMIN_TOTP. Details: docs/authentication.md.
- The conversation's full-screen toggle is an icon in the chat's bottom-right corner, like a video player's. On the phone it also hides the header, tabs and bottom bar.

Fixed
- The "jump to latest" button no longer sits on top of the full-screen icon.

Update note: no database changes.
