Aigentron v0.1.99

For people who are not programmers: a project that has its own channel no longer sends its messages into the main chat.

Fixed
- A project that named a channel but no chat got that channel together with the chat id from the global escalation setting, so a blocked, stalled or failed task of the project spoke into the wrong conversation (the main chat). Now the project's channel stands for all of its allowed chats when no chat id is given, and the global chat is used only when the project names no channel at all.
- Notices for the operators that belong to no project (low disk space and the like) are no longer sent into chats a project owns.
- Tasks already started in a chat keep that chat (their results, replies and approvals stay there); binding a channel afterwards does not move them. Tasks started from the dashboard are announced through the project's channel.

Update note: no database changes.
