Aigentron v0.1.36

For people who are not programmers: adding a provider in the terminal setup wizard now works the usual way, including subscriptions.

Setup wizard (node infra/setup-wizard.mjs)
- Adding a provider: name → how it signs in → protocol and address → model → limits → a quick test.
- Ways to sign in: API key, Claude subscription (Pro/Max), ChatGPT subscription via Codex (device-code sign-in), OpenAI key for Codex, bearer token, or no authentication for a local server.
- Subscriptions are handled in the wizard: it starts the login for you where it can, and tells you exactly what to do (for example, run it inside the container) where it cannot.
- Editing an existing provider shows how it signs in and its model, and a ChatGPT login can be renewed from there.
