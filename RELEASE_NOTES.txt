Aigentron v0.1.63

For people who are not programmers: mostly clean-up inside, plus smoother knowledge-base imports.

Knowledge base
- Adding a document, a note or a library resource no longer makes you wait: the request returns at once and the document is processed in the background. On the Knowledge page each new document shows its state (processing → ready, or the error); a failed one can be dismissed. If the server restarts while a document is still being processed, add it again.

Files
- Text files (Markdown, txt, csv, json …) open in the browser instead of downloading; videos in the workspace play with seeking; mkv/avi/3gp in the library are recognised as videos.
- Video summaries (frames and transcript) are now kept in one cache folder (cache/digests) instead of next to the video — old ones are moved automatically. Cleaning them up is part of the disk tidy-up as before.
- Optional: ATTACHMENTS_RETENTION_DAYS (off by default) deletes attachments of finished tasks after N days.

Inside
- One implementation of "is this path inside the allowed folder", one table of file types and one file upload/download code instead of several copies; one list of the agents' internal tools; one place for all dashboard requests (the dashboard code is a third shorter there) and one upload component. Behaviour is the same, there is less that can drift apart.
- New check "make test-di" (about a minute) that fails if a module is not wired into the application — it would have caught the start-up problem found in 0.1.61.
- The admin guide size check now counts the way the agent runtime does.

Update note: no database changes.
