Aigentron v0.1.117

For people who are not programmers: the number settings can be edited again, and taps on a phone no longer land on things you did not touch.

Fixed
- Settings → Task queue: the numbers (Concurrency, Chat slots, commands at once, pauses) could not be changed — erasing a digit switched the field to "automatic" and locked it. All number fields in the dashboard (schedules, voice, compression, run limits, verification attempts, knowledge chunking) now behave like normal text while you type and apply only a valid number.
- On a phone, the floating assistant no longer takes taps meant for the page under its empty corners (only the round mascot and its hide button react), and a tap next to the text of a checkbox no longer flips it.

Update note: no database changes.
