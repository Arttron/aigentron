Aigentron v0.1.74

For people who are not programmers: the admin can look at your screenshots, messages show up at once, tables look like tables.

New
- The admin assistant can open attachments. Ask it about a screenshot from a task page and it finds that task's files; look_at / video_digest accept just the file name. (Before it said it could not find the picture, from the task page and from Telegram alike.)
- A message you send appears in the conversation immediately ("sending…") instead of when the agent run starts — noticeable on a busy server.
- Tables in chat are real tables: aligned columns, numbers lined up on the right, zebra rows, sideways scroll on a phone. The admin's answers are now rendered as formatted text (bold, lists, code, tables) instead of raw symbols.
- The repository address is checked as you type: an SSH key needs an SSH address (git@github.com:org/repo.git), a token needs https, and a password never goes into the address. One button converts the address; Save is blocked while it is wrong.
- The update dialog says the server is down for 2–4 minutes and not to restart it by hand; the installer log lines carry the time.

Fixed
- On a phone the bottom navigation bar covered the message box of the task screen; the screen now stops above the bar.

Update note: no database changes.
