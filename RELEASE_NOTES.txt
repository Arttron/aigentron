Aigentron v0.1.95

For people who are not programmers: a safer approval system (after an independent review), usage statistics by project and by day, and the project as the context of the task page.

New
- Usage statistics (Stats): three views — by provider, by project, by day — a project selector, and tick boxes that switch the columns off (sessions, requests, input, output, cache, cost). The per-day view draws a column per day in your own time zone.
- The task page has a Project selector at the top. It is the context of the page: the list, its counters and the New task form belong to the chosen project (All projects shows everything and keeps the project picker in the form).
- Your own alert sound: upload up to five short audio files (mp3, wav, ogg, m4a; 1 MB, 15 s) in Settings → General → Alert sound. They stay in your browser.

Fixed
- Choosing a status in the task list showed subtasks; it now lists the main tasks (a task matches when its own status or one of its subtasks' is the chosen one). The counters on the status chips follow the same rule and the chosen project.
- Approvals, after a review of the whole system:
  - the browser could be sent to another site without a card by unusual address spellings (//host, https:\\host, a tab inside the scheme); addresses are now read the way the browser reads them, and the tracked page follows "back" and tab changes;
  - merges are recognised in every form (git -C … merge, git --no-pager merge …), and so are pushes naming main/master in quotes, with --all/--mirror, or through GitHub tools;
  - writes to protected files (.github, .git/hooks, agent definitions) are asked about whether the path is written absolute or relative, from the shell too; `git config` that makes git run a program is asked about;
  - listing the environment (printenv, env) or putting a variable named like a secret into a command is asked about, and so are web requests with a value taken from the shell;
  - writes outside the working directory are caught through quotes, variables, sh -c, find -delete, curl -o, tar -C and similar; plain copying FROM another folder, `git checkout -b x origin/main` and "merge main" in a commit message no longer raise a card;
  - when the dock, a Telegram button and a 👍 answer at the same moment, only the first one counts (before, a continuation could start twice).

Update note: no database changes.
