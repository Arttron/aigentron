Aigentron v0.1.28

A terminal-style conversation view, and a few fixes on top of 0.1.27.

Conversation
- The task conversation now reads like a terminal: you> / agent> / done> prompts, a blinking cursor while the agent works,
  and each tool call folded into one quiet line with its result (click to expand).
- Two looks, switchable above the conversation and remembered per browser: "terminal" (light-green text on near-black in the
  dark theme, deep-green ink on warm paper in the light theme — both checked for contrast) and "classic".
- "messages only" hides the tool steps; a "↓ latest" button appears when you scroll up during a run.
- Replies are rendered as Markdown (headings, lists, quotes, code blocks with a copy button, links). The renderer is
  built in, never inserts raw HTML, and only opens http(s)/mailto links.
- The message box: Enter sends, Shift+Enter adds a line (Cmd/Ctrl+Enter still sends).

Fixes
- No more "Permission deny rule NotebookRead / LS matches no known tool" warnings when the admin or researcher starts.
- The admin's local change journal (admin-audit.jsonl) is no longer part of the repository or the images.
