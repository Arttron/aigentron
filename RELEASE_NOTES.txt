Aigentron v0.2.2

For people who are not programmers: the program for your own computer is now simply called "aigentron", and the installer says so if the server's own "aigentron" tool would get in the way.

Changed
- The local agent program is installed as "aigentron" (before: "aigentron-local", which stays as another name for the same program). Commands and hints on the Add-ons -> Local agent tab, in the program and in the administrator's reference use the new name. An existing pairing keeps working.
- If another "aigentron" (the server's command-line tool) is found first in your PATH, the installer tells you and shows which one to call.
