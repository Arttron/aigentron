Aigentron v0.1.92

For people who are not programmers: the Playwright and Browser add-ons now install on newer servers, such as Ubuntu 26.04.

Fixed
- `sudo aigentron addon enable playwright` (and the Browser add-on) refused any system that was not on a fixed list, so Ubuntu 26.04 was rejected with "this add-on supports Debian 11/12/13, Ubuntu 22.04/24.04 …". Debian 11 or newer and Ubuntu 22.04 or newer are accepted now; a version newer than the ones it was tried on gets a warning and the install goes ahead.
- A library renamed by a newer release (the `t64` suffix) is found by itself, and one that no longer exists is skipped with a warning instead of stopping the install. At the end the add-on starts the browser as a self-test, which shows whether everything works.

Update note: no database changes. After updating, run `sudo aigentron addon enable playwright` again.
