Aigentron v0.1.53

For people who are not programmers: agents can talk to each other, show you pictures and albums, and use a browser through your proxy; uploaded pictures are shrunk automatically; plus a round of fixes from a code review.

Agents discuss with each other
- New "💬 Discuss" (on the New task form and in a chat's header): pick 2–6 agents, a topic and the number of rounds. The agents answer each other in turn, right in the chat, each message labelled with who said it. In Telegram: /discuss pm architect: topic.
- You can join in at any moment (they answer you first), press "Wrap up" for the conclusion, or stop it. If everyone agrees, it ends early. A provider error is never shown as something an agent said.

Pictures
- Agents can show one picture or an album (up to 10) in the chat: large single picture or a grid in the dashboard (click to open, arrows to step through), a photo or album in Telegram.
- Every uploaded picture is shrunk to what is needed (long side up to 1600 px, JPEG, location data removed; transparent PNGs stay PNG). Same for screenshots made by agents and for the library.

Browser through a proxy
- A second browser service sends all its traffic through your proxy (for geo-blocked sites or IP-bound pages). Put PLAYWRIGHT_PROXY_SERVER (host:port), PLAYWRIGHT_PROXY_USER and PLAYWRIGHT_PROXY_PASS in the server's .env and start it with: docker compose --profile proxy up -d playwright-mcp-proxy. Agents use it as the "playwright-proxy" MCP server. The browser can no longer open local files or browser pages, and the proxy login is not left in the container's environment.

Agents find each other
- The lead agent is told exactly how to reach each colleague. Agents on Codex or on a subscription login are not available to the Task tool — they are started as subtasks. Names like expert_codex / expert-codex are accepted. This fixes "Agent type … not found. Available agents: none".

Vision
- If no vision model is set up, look_at uses the agent's own cloud model (Claude / OpenAI-style). Settings → Vision shows unsaved changes, and Test saves them first.

Knowledge bases — fixes from a review
- Large bases no longer freeze the server while the index is built; the index is always current; changing the embedding model can no longer mix vectors; an agent that cannot be identified sees only open bases; passages are handed to agents as quoted data; PDF and Word reading has limits; Chinese/Japanese text is searchable. A base now holds up to 20,000 passages.

Update note: this release adds one small column for discussion messages; it is created automatically when the server starts. To use the proxy browser, add the three PLAYWRIGHT_PROXY_* lines to .env and start the new service as above.
