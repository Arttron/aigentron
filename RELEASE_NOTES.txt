Aigentron v0.1.78

For people who are not programmers: pinned agents per project, and pasted terminal output / code is formatted for you.

New
- Pin agents to a project. In the project's settings tick the agents that belong to it; the "New task" list of that project then offers only those. Nothing ticked = every agent, exactly as before. (It only narrows the list people see: schedules, leads and the admin can still start any agent.)
- Paste terminal output, logs, code, diffs or JSON into a chat box (a task, the admin chat, the new-task box) and it arrives as a formatted block — the language is detected from the text, colour codes from a terminal are removed, and ordinary text is never touched. A line under the box offers "paste as plain text". Blocks are shown as terminal-style code blocks with a copy button.

Update note: the database gets one small new column (a nullable text on projects); a snapshot is taken first and nothing existing changes.
