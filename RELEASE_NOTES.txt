Aigentron v0.1.45

For people who are not programmers: the terminal menu no longer asks the same technical questions every time.

The `aigentron` command
- It no longer asks "How is Aigentron installed here?" and for the server address each time: the command already knows them. Run directly, the menu asks once on the first launch and remembers the answer. A new "Connection" section (`aigentron connection`) changes it when needed.
- Every command goes straight to its section: `aigentron providers`, `channels`, `agents`, `repo`, `access`, and the new `advanced`.
- The closing "Done" block appears only after the full guided setup, not on every exit.
