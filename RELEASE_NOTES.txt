Aigentron v0.2.6

For people who are not programmers: the program on your computer can now update itself with one command.

Added
- "aigentron update" installs the version of the server your computer is paired with. It downloads the program from that server, checks it, tries it once, and only then replaces the old one (kept next to it as a backup with the ending ".prev"). If the background service is running, it is restarted. "aigentron update --check" only tells you whether there is a new version.
- The Local agent tab now points to this command when a computer is out of date.
- Nothing updates in the background by itself, and development copies (aigentron-dev) are never changed this way.

Note
- Computers with an older program (before 0.2.6) do not have this command yet: run the install command from the tab once more, after that "aigentron update" is enough.
