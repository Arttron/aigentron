Aigentron v0.1.90

For people who are not programmers: a messenger chat can now belong to one project, and messages in Telegram no longer turn file names into links.

New
- A chat tied to a project works only with it. When a project's notification channel and chat are set (the project's settings), that chat shows only the project's tasks in /tasks, starts new tasks (a message or a file) in the project, ignores replies and buttons of other projects' tasks, and does not get escalations of other projects. /settings names the project. If two projects point at the same chat, nothing is narrowed.
- Telegram messages are formatted: bold, italic, code, code blocks, headings, bullet lists and [text](https://…) links appear as formatting instead of stray ** and backticks.

Fixed
- File names such as progress.md or english/plan.md were shown as links to websites (.md, .sh, .py … are real internet domains). File names and paths are now shown as code and are never linked.
- If Telegram refuses a message's formatting, the same text is sent plain, so no message is lost.

Update note: no database changes.
