Aigentron v0.1.32

For people who are not programmers: you can now talk to the assistant and hear its answers.

Update note: this release adds one small database column (a per-chat "voice replies" switch). It is created automatically when the server starts.

Voice (Settings → Voice)
- Speech recognition: Telegram voice messages and the 🎤 button in the dashboard turn your speech into text.
- Speech synthesis: answers can be read aloud. By default answers stay text — voice is switched on separately.
- Works with OpenAI, Groq or any OpenAI-compatible server (including one on your own machine) — add it as a provider of kind OpenAI, pick it in Settings → Voice.
- "Try it" on the same tab: hear the chosen voice and record yourself to see what is recognised. Cloud providers receive your audio / the read text — the page says so.

In the dashboard
- Voice mode: the message box is replaced by a calm orb that shows listening, thinking and speaking. Speak, pause, hear the answer; optional "keep listening".
- "Speak" switch: read the latest answers aloud; one replay button on the latest answer.
- The same controls sit in the same place in both modes, so nothing jumps.
- The microphone needs https or localhost (a note in docs/voice.md).

In Telegram
- Send a voice message — the bot replies in text, with the recognised words echoed.
- /voice on and /voice off — the bot answers with voice in that chat.
