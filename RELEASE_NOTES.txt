Aigentron v0.2.3

For people who are not programmers: the program on your computer can now fetch a project's code by itself, or work right in the folder you start it from.

Added
- "aigentron open <project>": from any folder, picks one of the server's projects that has a repository, uses the copy that is already on your computer or downloads it (you confirm the address and the folder first) and allows the agent to work in it. "aigentron open" alone lists the projects.
- Starting "aigentron chat" or "aigentron run" inside a git repository that is not allowed yet asks once whether to allow it.

Safe by design
- The server can only name a project. The program checks the address itself (no local paths, no passwords, no commands) and runs the download without any hooks of the repository.
- The server needs this version too: older servers answer "too old to list projects".
