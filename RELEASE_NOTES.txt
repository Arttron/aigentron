Aigentron v0.1.33

For people who are not programmers: a small security fix and a tidier voice experience.

Security
- Sign-in attempts are now limited more reliably: guessing a password could no longer be sped up by faking the "client address" header when connecting directly (home network, IP address, port forwarding). Behind a Cloudflare tunnel nothing changes for normal use.

Voice
- Voice mode and the "Speak" switch sit in the same strip in both modes, with clearer icons, and nothing jumps when switching.
- One read-aloud button on the latest answer only; it no longer moves the text.
- Settings → Voice has a hands-on "Try it": hear the voice and record yourself to see what is recognised.

Notes
- Agents with a shell can still reach the server's sign-in key file; separating agents from it is the next planned security step (see docs/BACKLOG.md).
