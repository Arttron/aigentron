Aigentron v0.1.65

For people who are not programmers: a new optional "Browser" add-on — a real Chrome/Chromium on your server that you can watch and operate from the dashboard (and that agents will be able to drive in the next step).

Add-ons
- New command on the server: "aigentron addon list | enable | disable | status | logs <name>" (add --dry-run to see what would happen). Enabling needs sudo and is always run by a person on the server — the dashboard only shows the exact command.
- First add-on: "browser". On a stand-alone (systemd) server it installs a virtual screen, a light window manager and a browser (Google Chrome on x86, otherwise Chromium) under its own system user, everything listening on localhost only. On a Docker install it starts a separate container from the same installer script. Tested on Debian 12, Ubuntu 24.04 and Amazon Linux 2023 (systemd containers) and as a Docker image. Needs about 2 GB of memory and disk; idle it uses roughly 250 MB.
- New page "🌐 Browser" in the header: a live desktop with the browser, only after you sign in and only for operators/admins, through your usual address (no extra ports are opened). Up to 3 viewers at a time and a session time limit (2 hours by default); who opened it is written to the log. If the add-on is not installed the page shows what it is, what it needs and the commands to run.
- Important: in this first version there is ONE browser profile and agents do not drive it yet. Whatever you sign in to there is visible to the agents later — so sign in only to what you are fine sharing. A separate personal profile and a safe "go-between" for agents come next.

Developer stack
- The dev server now receives all environment variables (the build tool used to hide the new ones).

Update note: no database changes.
