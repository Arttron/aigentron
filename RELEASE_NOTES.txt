Aigentron v0.1.112

For people who are not programmers: a click on the browser extension's notification now always takes you somewhere useful.

Fixed
- Clicking a notification from the extension sometimes did nothing (when the request had already been answered, or the extension had just woken up). Now it always opens the dashboard: the task if it is known, the main page if not, and it switches to a tab that is already open instead of opening another.

Update note: update the extension (its icon → "Update the extension"). No database changes.
