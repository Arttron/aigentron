Aigentron v0.1.68

For people who are not programmers: resources and knowledge bases can now belong to a single project.

Scopes
- A resource (note, photo, document) or a knowledge base is either GLOBAL — seen by the agents of every project, exactly as before — or belongs to ONE project and is seen only by the agents working on that project. Everything you have now stays global.
- On the Resources and Knowledge pages a bar "All · Global · <projects>" filters the list; new notes, uploads and bases are created in the selected scope, and an item can be moved between global and a project in its edit dialog. With a single project nothing changes on screen.
- An agent of project A sees the global resources and A's own, never another project's; the knowledge tools list their scope (global / project). The resource library of a project lives in its own folder.
- Project page: counts of its resources and bases with links to the filtered lists. Deleting a project asks what to do with its knowledge bases and resources: by default they become global (nothing is lost); you can also delete them with the project.
- The admin can propose a resource or a pack for a given project.

Update note: the database gets a small migration (a project link on knowledge bases; existing bases stay global); a snapshot is taken first.
