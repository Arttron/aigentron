Aigentron v0.1.121

For people who are not programmers: the browser extension's chat now works like the main one, the extension stops refusing to work when you are not really using the page, and an old open tab tells you to reload.

New
- The extension's side-panel chat shows what you send at once ("sending…"), lists the server's queue (with edit and remove), sends on Enter, and formats and quotes like the dashboard.
- The dashboard notices when the server was updated while the tab was open and shows "Aigentron was updated — reload this page" with a Reload button. (A tab left open across an update keeps running the old code, so a fixed bug can look not fixed.)

Fixed
- The extension refused to act "because you are using this tab" when you had only scrolled. Now scrolling does not count, only a click or a key press for 1.5 s, and the extension waits and retries by itself before the agent hears of it.
- Pressing Approve on the in-page card counted as "using the tab", so the agent's next click was refused and the task became blocked. Clicks on the extension's own cards no longer count, and an action you have just approved is never refused for that reason.
- Editing a queued message in the extension no longer sends it twice when its removal failed; a slow send no longer writes into another conversation; a message is shown once; long unfinished links no longer slow the panel.
- In the dashboard, a message taken out of the queue no longer comes back as "sending…".

Update note: update the extension too (its icon → "Update the extension").
