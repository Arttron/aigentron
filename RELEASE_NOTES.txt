Aigentron v0.1.57

For people who are not programmers: pictures made by Codex reach you by themselves, every message can be copied, and a reply in Telegram goes to the task that just asked you something, and the admin can read the text files you send it.

Pictures from Codex
- Codex generates images into its own sandbox, where you could not see them (and copying them needed an approval that sometimes timed out). Now the new pictures are attached to the task and shown in the chat (and Telegram) right after the run — nothing to approve. You can also ask the agent to "show" such a picture again.

Copy a message
- A small copy icon under every message in the task chat (yours and the agent's) and in the chat with the admin. It works on plain HTTP addresses too.

Files for the admin
- You can attach a text file (Markdown, txt, csv, json …) to a message for the admin, in the dashboard or in Telegram: it now reads it (before it answered that it could not open attachments). Pictures are looked at, other formats (PDF, Word) are reported as unreadable so it asks for the text.

Telegram
- When a task becomes blocked and asks you something in a chat, your next plain message answers THAT task (before, it could go to whichever task was active earlier, so lesson answers landed in the wrong place). Replying (quoting) to a specific message still addresses that message's task; with several tasks waiting at once, quote the one you answer.

Update note: no database changes.
