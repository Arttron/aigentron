Aigentron v0.1.37

For people who are not programmers: one command, `aigentron`, to manage the server from the terminal.

The `aigentron` command (installed with the server)
- `aigentron` opens the setup menu: providers, channels, agents, repository, advanced. `aigentron providers | channels | agents | repo` jump straight to a section.
- `aigentron status | start | stop | restart | logs` — run and watch the server.
- `aigentron doctor` — checks the common problems (service running, port answers, disk, memory, LiteLLM not exposed, a newer release available).
- `aigentron update` — installs the latest release and keeps your data and settings.
- `aigentron reset-password` — forgot the dashboard password? Removes all passwords after a confirmation.
- `aigentron admin` — chat with the admin assistant in the terminal; `-h` on any command shows help; `-v` shows the version.
- Works for both the Docker and the bare-metal install. Servers installed earlier get the command after one update.
