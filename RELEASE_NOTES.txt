Aigentron v0.1.56

For people who are not programmers: the team now has a shared workspace for its non-code work, with a page where you can see and use the files.

Shared workspace
- A folder with a fixed structure that every agent knows: WORKSPACE.md (a short brief — you write it), memory/ (decisions, open questions, facts, plan, status — agents write there and read it at the start of every task), work/ (drafts and data), deliverables/ (finished results for you; older versions are kept). Your answers to an agent's questions are written to the decisions automatically.
- New page "📁 Workspace" (top menu): browse the folders, preview Markdown/text/images/PDF, download, upload into work/, delete in work/ and deliverables/, edit the brief. The first row ".." goes up one level and carries the folder's Upload action. Its size is shown in Settings → General → Disk & cleanup and it is never cleaned automatically.
- A result an agent saves to deliverables/ also appears in that task's attachments (gallery, chat, Telegram) as a link — the file is not copied, so you always see its current version.
- Nothing to set up: the folder appears by itself (in the dev setup run "docker compose up -d" once to mount ./workspace). Existing data is untouched.

Telegram
- No "Mark done" button under answers any more: write "done" (or /done) to close a task. Buttons in old messages still work.

Small things
- The "Name tasks automatically" checkbox in Settings no longer stretches across the card.

Update note: no database changes.
