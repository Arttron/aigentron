Aigentron v0.1.96

For people who are not programmers: while the server updates, anyone who opens the dashboard now sees what is going on instead of an error.

New
- An "Updating Aigentron" page while the server is down during an update (bare-metal installs): it shows the steps (stopping, saving the database, updating it, switching, starting) and a timer, and the page reloads by itself when the new version answers. It also covers the case when the new version does not start and the previous one is being restored. A dashboard tab that is already open shows a banner "Aigentron is updating" and reloads by itself (from the next update on: tabs opened with an older version only get the errors they used to). It shows only the announced steps — no log lines, no paths. Set NO_UPDATE_PAGE=1 for the installer to switch it off. Details: docs/updates.md.

Update note: no database changes. The first update that uses this is the update TO this version's installer, so you can watch the page during it.
