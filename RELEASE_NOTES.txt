Aigentron v0.1.39

For people who are not programmers: managing providers from the terminal is now complete, and the setup wizard asks for your password when the server has one.

Providers in the terminal (`aigentron providers`)
- One menu: add, edit, set the default, test and delete providers. The list shows each provider's type, how it signs in and its model, and marks the default with a star.
- Editing a provider (model, address, key or sign-in, rate limits) ends with "Make it the default provider?" — no more hunting for where to set the default.
- Deleting the default provider asks which one should take over.

Setup wizard
- When the server has a sign-in password, the wizard now asks for it first (a hidden field; with several users it asks who you are). Before, every list looked empty.
- Editing a channel no longer clears its default agent by accident, even if that agent no longer exists.
- `aigentron version` always prints something sensible, also for a Docker install without a version label.
