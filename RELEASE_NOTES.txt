Aigentron v0.1.111

For people who are not programmers: agents read more pages in your browser, and your queued messages no longer disappear.

Fixed
- Messages you send while an agent is still working stay visible in the chat after you refresh the page (in task chats and in the admin chat), marked as queued.
- When you allow agents to use your browser, Add-ons → Extension notices it at once instead of showing the old warning.

Improved
- Pages Chrome refuses to let extensions touch (the Chrome Web Store, chrome:// pages) are now read from their source: title, descriptions, structured data and visible text, with a note about what may be missing.
- If the source is almost empty (a page drawn by scripts), the extension takes a screenshot as a last step: the vision model turns it into text, or the agent gets the image. The browser screenshot tool can also take a question about the picture.

Update note: update the extension (its icon → "Update the extension"). No database changes.
