Aigentron v0.1.58

For people who are not programmers: the admin can now read the files you give it.

Files for the admin
- The admin has no file reader of its own, so it used to answer "I cannot open attachments" — even for a file you had uploaded to the task. Now it has a tool to read the text of a task's attachment (also one uploaded later in the Files tab, by name), or a file of the workspace or the library: Markdown, text, CSV, JSON, HTML, PDF with a text layer and Word (.docx), 12 000 characters at a time (it asks for the next part itself). Pictures are looked at; scans without text are reported as unreadable.
- The same tool is given to any agent whose allowed tools do not include Read.

Update note: no database changes.
