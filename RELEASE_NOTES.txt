Aigentron v0.1.89

For people who are not programmers: agents can now pull the latest code of a project that uses an SSH key, and they know the settings of the project they work in.

New
- Agents can fetch the project's remote: a new `fetch_remote` tool (no approval needed). Before, an agent's own `git pull` failed with "Host key verification failed" because agents hold no keys by design; now the server fetches with the project's key, and the agent merges the new commits itself. Nothing of the agent's files or branches changes by the fetch.
- Every agent working in a code project is told that project's settings: repository and base branch, how the remote is reached, shared or worktree mode, subdirectory and the checks that run afterwards, and that remote git goes through `fetch_remote` / `push_branch`.

Fixed
- Projects → Repository → "Sync now" showed a cross and no text after a successful sync. It now shows a tick, what was done and the short commit id.
- The `git` skill told agents to switch to `develop` and `git pull`, said plain `git fetch` authenticates itself and that a local merge needs approval; all of that is corrected. The `playwright` skill no longer calls the Docker sample app "the base project".

Update note: no database changes.
