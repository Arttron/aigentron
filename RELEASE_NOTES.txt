Aigentron v0.1.128

For people who are not programmers: `aigentron addon enable` works again on a server without Docker, and an agent can show you a screenshot from the server's Playwright browser in the chat.

Fixed
- `sudo aigentron addon enable <name>` failed on every server installed without Docker with «DATA_DIR=/opt/aigentron/data: not found», so no add-on (Browser, Playwright, Voice) could be enabled or re-enabled from the command line. Fixed. (On 0.1.127 you can still run the installer directly: `sudo env DATA_DIR=/opt/aigentron/data bash /opt/aigentron/current/infra/addons/playwright/bare.sh install`.)
- A screenshot taken with the server's Playwright browser could not be put into the chat: the browser saves it in its own folder, out of the agent's reach, and the agent said "sent" anyway. The Playwright add-on now saves screenshots in /var/lib/aigentron-playwright/output, the agent can show them with show_images, and its instructions say to report "sent" only after the picture was really shown.

Update note: after updating, run `sudo aigentron addon enable playwright` once on a server without Docker — it rewrites the Playwright service (the screenshot folder, and the proxy gateway if the 0.1.127 step was not done yet) and restarts it. A Docker install is unchanged: there the agent can still only look at a screenshot, not show it.
