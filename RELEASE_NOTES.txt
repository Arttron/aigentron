Aigentron v0.1.49

For people who are not programmers: see and end who is signed in, and the ChatGPT (Codex) provider works properly.

Signed-in devices (Settings → Signed-in devices)
- A new tab lists every browser or device that is signed in: which one (for example "Chrome on macOS"), from which address, when it signed in and when it was last active. Each has a "Sign out" button and the device is signed out at once.
- You see your own devices; an operator or admin sees everybody's and can sign a person out everywhere (their password stays). "Sign out my other devices" ends all your other sessions and keeps this one.
- Changing or resetting someone's password now signs that person out on every device.

ChatGPT (Codex) provider
- The model picker lists the models Codex itself offers for your account, instead of a single fixed name.
- Fixed: testing the provider before signing in showed an error about a missing CODEX_HOME folder. The folder is now created, the CLI's warning noise is gone, and the message tells you how to sign in (`aigentron providers` → Edit → sign in again).

Update note: this release adds a small table for the device list; it is created automatically when the server starts. Sessions that were already signed in keep working but appear in the list only after the next sign-in.
