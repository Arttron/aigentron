Aigentron v0.2.1

For people who are not programmers: the local agent now connects through the address your server is normally opened at (the "520" error behind a tunnel or proxy is gone), and the list of connected computers is easier to read.

Fixed
- The local agent could not connect when the server is reached through its built-in web server (ports 80/443), for example behind a Cloudflare tunnel: the connection was dropped and the error 520 was shown. It connects there now.

Changed
- Add-ons -> Local agent: each connected computer is a card (name and status, then user, system, version and when it was last seen, with Disconnect on the side). A development build shows its version as it is.
- A development build of the program (aigentron-dev, made with "make local-agent-dev") keeps its own settings and can run next to the installed one; it is never shown as "update available".
