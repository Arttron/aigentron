Aigentron v0.1.127

For people who are not programmers: the proxy chosen for the agents' browser is now really used on a server where the Playwright add-on is installed without Docker.

Fixed
- On a bare-metal server the Playwright add-on's service started the browser without any proxy option, so the proxy chosen in Add-ons → Playwright → Browser proxy (or by an agent) was ignored: pages showed the server's own address. The add-on's installer now points the browser at the server's proxy gateway (port 8940, or PROXY_GATEWAY_PORT of the server; none when the gateway is switched off).

Update note: after updating, run `sudo aigentron addon enable playwright` once on such a server — it rewrites the service and restarts it. (Without waiting for the update you can do it by hand: docs/browser-proxy.md, "bare-metal Playwright add-on".) Then ask an agent to open a page that shows the IP address: with a proxy chosen it must show the proxy's address, not the server's.
