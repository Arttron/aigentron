Aigentron v0.1.43

For people who are not programmers: newer Claude models now work, and the terminal menu behaves better in narrow windows.

Claude models
- The built-in Claude Code engine is updated (2.1.295). Newer models such as claude-opus-5-5 need it; before, a task on such a model failed with "Claude Code 2.1.193 does not support this model; version 2.1.280 or newer is required".

Setup wizard (`aigentron`)
- Yes/No questions and menu headers stay on one line in a narrow terminal (a wrapped line used to be redrawn as a growing pile of copies).
- A Claude subscription login is no longer reported as "test failed": it cannot be checked with a quick request, so the wizard says so and skips the test — start a small task with that provider to confirm it works.
