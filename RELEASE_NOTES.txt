Aigentron v0.1.110

For people who are not programmers: agents can now actually use your browser, once you allow it with one button.

Fixed
- Agents in your browser (the extension) failed on real sites with "This tab is not showing a web page", and the open tabs showed no title or address. The cause was that Chrome had not given the extension access to websites, and nothing asked for it in the right words. Now the agent is told plainly what is missing before you are asked to approve a site, the extension's icon shows a notice and a button "Allow agents to use my browser" (Chrome asks once), and Add-ons → Extension warns which browsers still have no access. Agents still work only in their own window, only on sites you approve for each task, ask you before every form is sent, never fill passwords or cards, and never touch banks, mail or the dashboard.

To use it: update the extension (its icon → "Update the extension"), press "Allow agents to use my browser", and ask the agent again.

Update note: no database changes.
